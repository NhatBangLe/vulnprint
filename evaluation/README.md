# 🔬 Vulnprint Evaluation Harness

A Python CLI evaluation framework designed to run, record, reproduce, and manage benchmark evaluations on **Vulnprint**.

---

## 🎯 Key Capabilities

1. **Environment Configuration Export & Reproduction**:
   - Captures host environment, Python runtime, Git commit hash, dataset SHA-256 checksum, AI model hyperparameters, Metasploit RPC settings, and MCP options.
   - Exports the validated configuration into a structured `config.json` via **Pydantic**.
   - Enables 100% reproducible evaluations via `reproduce -c <config.json>`.

2. **Self-Contained & Ordered Turn Directories**:
   - Each evaluation turn isolates its own database, generated blueprints, stdout/stderr log, and configuration file in order:
   ```
   evaluation/runs/run_001/
   ├── config.json          # Complete exported environment & execution config (Pydantic model)
   ├── sqlite.db            # Turn-specific SQLite database generated by Vulnprint
   ├── blueprints/          # Directory containing all generated Markdown lab blueprint manuals
   │   ├── exploit_linux_http_avideo_encoder_getimage_cmd_injection.md
   │   └── ...
   └── run.log              # Stdout/stderr execution stream log
   ```

## 🚀 Quick Start

### 1. Run Default Benchmark Evaluation
Executes Vulnprint on the benchmark dataset (`evaluation_data/msf_paths.json`) and automatically saves outputs in `evaluation/runs/run_001/`:
```bash
python evaluation/cli.py run
```

### 2. Run with Custom Parameters & Limit
```bash
python evaluation/cli.py run \
  --input-file evaluation_data/msf_paths.json \
  --limit 5 \
  --ai-model llama3 \
  --ai-temperature 0.2 \
  --run-name run_llama3_temp0.2 \
  --tag "Testing llama3 at low temperature"
```

### 3. Target Custom Output Folder (e.g. `RUN/`)
```bash
python evaluation/cli.py run -o RUN --run-name RUN_vulprint_4
```

### 4. Reproduce an Evaluation from Exported `config.json`
```bash
# Dry run to preview reproduction parameters:
python evaluation/cli.py reproduce -c evaluation/runs/run_001/config.json --dry-run

# Execute reproduction:
python evaluation/cli.py reproduce -c evaluation/runs/run_001/config.json
```

### 5. List Recorded Evaluation Turns
```bash
# List runs in default evaluation/runs/
python evaluation/cli.py list

# List runs in RUN/
python evaluation/cli.py list -o RUN
```

### 6. Export Configuration Template
```bash
python evaluation/cli.py export-config -o config.template.json
```

## ⚙️ CLI Reference

### `run`
| Flag | Description | Default |
|------|-------------|---------|
| `-f`, `--file`, `--input-file` | Path to module list (JSON array, JSONL, or text) | `evaluation_data/msf_paths.json` |
| `-q`, `--query` | Metasploit search query / filter | `None` |
| `-l`, `--limit` | Cap maximum modules to process | `None` |
| `--min-date`, `--max-date` | Date range filter (`YYYY-MM-DD`) | `None` |
| `--sort-date` | Sort by date (`asc` or `desc`) | `None` |
| `--ai-model` | AI model override | From env / settings |
| `--ai-base-url` | AI API endpoint URL | From env / settings |
| `--ai-temperature` | Sampling temperature (`0.0` - `2.0`) | From env / settings |
| `--ai-api-key` | AI API key override | From env / settings |
| `--msf-host`, `--msf-port`, `--msf-password` | Metasploit RPC daemon overrides | `127.0.0.1:55553` |
| `--msf-version` | Optional Metasploit version string for tracking purpose (e.g. `6.4.15`) | `None` |
| `--mcp-url`, `--mcp-max-calls` | MCP search server overrides | `http://localhost:8000/mcp` |
| `-o`, `--output-dir` | Base directory for runs | `evaluation/runs` |
| `--run-name` | Specific turn name | Auto-incremented `run_001`... |
| `--tag` | Metadata label/description | `None` |
| `--export-secrets` | Export raw API keys/passwords in JSON | `False` (masked references) |

### `reproduce`
| Flag | Description | Default |
|------|-------------|---------|
| `-c`, `--config` | Path to source `config.json` | *Required* |
| `-o`, `--output-dir` | Target output directory | `evaluation/runs` |
| `--run-name` | Target reproduced turn name | `<source_name>_reproduced` |
| `--dry-run` | Preview reproduction parameters | `False` |
| `--export-secrets` | Export raw credentials in target JSON | `False` |
